# 🍽️ Sistema de Agendamento de Reservas - Painel do Atendente

> Sistema web desenvolvido em React para auxiliar os atendentes de restaurantes no gerenciamento, controle e cadastro de reservas de mesas de forma rápida e intuitiva.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

* **React**
* **JavaScript**
* **HTML**
* **CSS**

---

## ✨ Funcionalidades

* **Visualização de Reservas:** Lista de reservas do dia organizadas por horários e mesas.
* **Nova Reserva:** Formulário para cadastrar clientes, número de pessoas, horário e data.
* **Edição e Cancelamento:** Capacidade de alterar dados da reserva ou excluir.
* **Filtros e Busca:** Busca rápida por nome do cliente ou horário.

---

## 📦 Como Rodar o Projeto Localmente

Siga os passos abaixo para executar o projeto na sua máquina:

### Pré-requisitos
- Certifique-se de ter o **Node.js** e o **npm** (ou **yarn** / **pnpm**) instalados na sua máquina.

- Digite npm install e em seguida acesse: http://localhost:3000/
